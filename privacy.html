水下钱庄 · 隐私政策

生效日期：2026 年 10 月 21 日（含第三方 SDK 完整披露）　|　适用游戏：《水下钱庄》
我们非常重视你的隐私。本游戏是一款单机休闲游戏， 核心玩法完全离线运行，不收集你的个人身份信息。 本政策会说明我们在哪些情况下会处理数据、处理什么、以及你拥有哪些权利。

一、我们收集哪些信息

本游戏在正常运行过程中，不会主动收集以下信息：

  • 姓名、身份证号、手机号、邮箱等个人身份信息
  • 通讯录、短信、通话记录
  • 精确地理位置
  • 照片、相册、麦克风、摄像头内容

以下信息会仅保存在你的设备本地，不会上传：

数据项 用途 存储位置
游戏进度（金币、背包、仓库、图鉴、天赋） 让你下次打开时继续游玩 设备本地存储（localStorage）
游戏设置（音量、画质偏好等） 记住你的偏好 设备本地存储

卸载游戏或清除应用数据后，上述本地数据将被删除，无法恢复。

二、第三方 SDK 情况说明

本游戏接入了以下第三方 SDK。我们按照监管要求，在此逐项披露各 SDK 的名称、 开发者、使用目的、使用场景、申请的权限、收集的个人信息类型及方式、 隐私政策链接，以及调用频次与时机。

披露项 内容
SDK 名称 TapADN SDK（TapADN 广告 SDK）
包名：com.tapsdk.tapad　版本：5.3.0.4
开发者名称（全称） 上海艾得蒽数字科技有限公司
使用目的 向用户展示激励视频广告；在用户完整观看后发放对应的游戏内奖励。 这是本游戏唯一的商业化方式，不涉及付费内购。
使用场景 仅在下列 4 个用户主动点击的场景中调用：
① 钓鱼界面背包已满 → 点击「看广告·临时扩背包」
② 宝库页面 → 点击「看广告·开箱必得多件」
③ 仓库页面 → 点击「看广告·直接领 5000 金」
④ 负面事件导致金币归零 → 点击「看广告·免除本次事件」
以上入口均由用户主动点击触发，游戏不会自动播放广告。
调用权限说明 本 App 向系统申请的权限及用途：
· INTERNET（访问网络）：请求广告素材与广告配置
· ACCESS_NETWORK_STATE（查看网络状态）：判断网络是否可用，选择合适素材
· REQUEST_INSTALL_PACKAGES（安装应用）：广告落地页下载安装 App 时使用
· QUERY_ALL_PACKAGES（查询已安装应用）：广告落地页判断微信等应用是否已安装
· com.asus.msa.SupplementaryDID.ACCESS、freemme.permission.msa： 用于读取 OAID（匿名设备标识符），仅在部分厂商设备上生效

以下敏感权限本 App 未申请、也不会申请：
精确定位、通讯录、短信、通话记录、相册、麦克风、摄像头、 日历、传感器（加速度计/陀螺仪）
个人信息收集类型及方式 收集类型：
· 设备标识符：OAID（匿名设备标识符）、Android ID
· 设备信息：设备型号、操作系统版本、屏幕分辨率、语言设置
· 网络信息：网络类型（WiFi/移动网络）、IP 地址
· 广告交互数据：广告展示、点击、关闭、观看完成状态

收集方式：由 SDK 在广告请求与展示过程中自动采集， 通过 HTTPS 加密传输至广告服务器。

我们不收集、SDK 也不采集：
姓名、身份证号、手机号、邮箱、通讯录、位置轨迹、 照片、生物识别信息、IMSI、IMEI
隐私政策链接 TapADN SDK 隐私政策：
https://ssp.dirichlet.cn/docs/agreement/
SDK 合规使用说明：
https://ssp.dirichlet.cn/docs/compliance/
频次与时机 调用时机：仅在用户点击上述 4 个广告入口时调用， 每次点击触发一次广告请求。
调用频次：无固定频次，完全由用户主动行为决定。
初始化时机：App 启动后延迟约 3 秒、且游戏画面显示完成后 才初始化 SDK（避免影响启动速度）。
预加载：SDK 就绪后会预先缓存广告素材（最多 3 个广告位各 1 支）， 用于减少用户点击后的等待时间。

2.3 未接入的第三方 SDK 声明

为避免误解，我们明确声明：本游戏未接入以下类型的第三方 SDK：

  • 统计分析类（如友盟、神策、GrowingIO、Google Analytics）
  • 推送通知类（如极光推送、个推、小米推送）
  • 社交登录类（如微信登录、QQ 登录、微博登录）
  • 支付类（如微信支付、支付宝）
  • 崩溃监控类（如 Bugly、Sentry）
  • 地图与定位类（如高德、百度地图）
  • 其他广告网络（如穿山甲、优量汇、快手联盟）

本游戏的游戏进度、金币、图鉴等全部数据仅保存在您的设备本地， 不上传至任何服务器。

在需要处理数据的场景下，我们仅用于：

  • 提供并维护游戏的核心功能

四、未成年人保护

本游戏适合全年龄段游玩，不含暴力、色情等不适宜内容。 若你是未满 14 周岁的儿童，请在监护人陪同下阅读本政策并使用本游戏。 我们不会主动收集未成年人的个人信息。

五、你的权利

你对自己的数据拥有以下权利：

  • 删除权：卸载游戏或清除应用数据，即可删除全部本地数据
  • 知情权：本页面完整说明了数据处理的场景和范围
  • 拒绝权：你可以选择不观看广告，不观看仅无法获得额外奖励，核心玩法完全不受影响
